### Remaining work on [Stabilize C-variadic function definitions — #727](https://github.com/rust-lang/fls/pull/727), including naked functions.

Pete: I'll review this afternoon / Monday and provide feedback.

Hristian: Here's an overview of the PR. I shifted some things around. There's a common syntax pattern between functions and function types. Both can have variadic parts. I wanted to refactor the variadic portions. The second big change is there's now a separate variadic function section. That's where the syntax for the variadic functions is and that's where you'll find the C-variadic functions.

Hristian: I also changed the `extern` functions. Some of the new rules change the functions declared in `extern` blocks and external qualifier. There are now two terms for each. They sound similar but they're significantly different to warrant separate entries.

Pete: At the very least they seem related so this makes sense. Thanks. I'll spend some time reviewing it this afternoon.

Hristian: Tshepang added the naked function stuff. I reviewed that and left some pointers he needs to address.

Pete: Looks like we're about a month out from 1.100. There's the `Allocator` stabilization, but that's mostly library stuff. But they're also stabilizing `!` (the never type).

Tomáš: The never type stabilization will introduce some breaking changes and they're also aliasing `Infallible` to `!`.

Pete: Never type stabilization PR: https://github.com/rust-lang/rust/pull/155499. This looks like a rough release.

Hristian: I hope this won't affect the type unification. That's one of the most difficult things to describe in the FLS.
